📱 1화면: 나의 구독 목록 관리 (My Subscriptions)
사용자가 현재 이용 중인 구독 서비스를 등록하고, 지출을 확인하며 관리하는 페이지입니다.

주요 기능 및 UI 요소:

월간 총지출 요약: 현재 활성화된 구독들의 총 결제 금액을 상단에 시각적으로 표시 (예: "이번 달 고정 지출: 45,000원").

구독 서비스 리스트:

서비스 로고/이름, 요금제 이름, 결제일(D-Day), 월 결제 금액 표시.

[토글 버튼]을 통해 '활성화/비활성화(숨김)' 상태 전환 가능.

해지 및 가입 링크 연동:

리스트의 서비스를 클릭하면 상세 모달(Modal)이나 페이지가 열림.

[해지하러 가기] 공식 버튼: 클릭 시 해당 서비스의 실제 해지 페이지 URL로 외부 링크 이동.

[재가입/공식 홈] 버튼 연동.

구독 추가 버튼 (+): 사용자가 직접 새로운 구독 서비스를 리스트에 추가하는 폼 (서비스명, 금액, 결제일 선택).

📱 2화면: 카테고리별 추천 및 리뷰 (Discover & Reviews)
새로운 구독 서비스를 탐색하고, 다른 사용자들의 실제 평가를 확인하는 페이지입니다.

주요 기능 및 UI 요소:

카테고리 탭 탐색: OTT(넷플릭스 등), 음악(스포티파이 등), 생활/배송(쿠팡 등), 생산성(Notion 등) 카테고리 필터링.

구독 서비스 추천 카드:

플랫폼 내 평점(★ 4.5), 대표 혜택 요약, 최저가 정보 표시.

클릭 시 상세 리뷰 페이지로 이동.

리뷰 시스템:

평점(별점): 1점~5점 선택 기능.

한줄평/리뷰 작성: 실제 사용해 본 장단점 기록 기능.

"가성비 점수" 또는 "이런 분께 추천해요" 태그: MVP 단계에서 유용한 간단한 선택형 태그 시스템.

3. MVP 데이터 구조 (Data Architecture)
Claude Code에게 백엔드(Supabase/Firebase) 테이블 생성을 요청할 때 사용할 가이드라인입니다.

1) users (사용자 테이블)
id, email, created_at

2) services (전체 구독 서비스 마스터 데이터)
id, name (서비스명), category (카테고리), logo_url, cancel_url (해지 링크), base_price (기본 금액)

3) user_subscriptions (사용자별 구독 목록 - 1화면용)
id, user_id, service_id, custom_price (사용자가 입력한 금액), billing_date (결제일), is_active (활성화 여부)

4) reviews (서비스 리뷰 데이터 - 2화면용)
id, user_id, service_id, rating (별점), content (리뷰 내용), created_at


디자인 콘셉트/톤앤매너:

깔끔함/신뢰감: 돈(고정 지출)을 다루는 앱이므로 정돈되고 신뢰감을 주는 UI (예: 화이트/그레이 베이스에 포인트 컬러 사용).

직관성/미니멀: MVP 특성상 복잡한 요소는 배제하고, 사용자가 '내 지출 금액'과 '해지 버튼'을 가장 먼저 인지할 수 있도록 설계.

주요 타겟: 2030 세대 1인 가구, OTT 및 각종 구독 서비스를 3개 이상 이용 중인 헤비 유저.

2. 디자인 핵심 규칙 (UI/UX 가이드라인)
모바일 퍼스트(Mobile-First): 웹으로 구현하지만 스마트폰 화면(예: 375px x 812px 스크린 기준)에서 가장 완벽하게 보여야 함.

고정형 하단 탭 바: 모바일 앱 UX를 위해 화면 하단에 늘 고정되는 네비게이션 바 필요 (1화면: 내 구독 / 2화면: 탐색·추천).

가독성 중심의 타이포그래피: 숫자가 많이 들어가는 앱(금액, 결제일 D-day 등)이므로 대시보드와 리스트의 숫자 가독성이 매우 중요함.

3. 화면별 세부 디자인 요구사항 (Wireframe & Component)
📱 1화면: 나의 구독 목록 관리 (My Subscriptions)
핵심 목표: 사용자가 이번 달에 총 얼마를 쓰는지 '충격'을 주고, 불필요한 구독을 빠르게 해지하도록 돕는 것.

상단 대시보드 영역:

이번 달 총 지출 금액이 가장 큰 폰트로 강조되어야 함.

지난달 대비 지출 변화나 절약한 금액을 서브 텍스트로 노출 (선택 사항).

구독 리스트 영역:

카드형 혹은 플랫 리스트 형태: 서비스 로고 아이콘, 서비스명, 요금제, D-Day(결제일까지 남은 일수)가 한눈에 들어와야 함.

상태 표시: 활성화된 구독과 비활성화(해지 예정/숨김)된 구독의 시각적 대비 필요 (비활성화는 딤드(Dimmed) 처리나 회색 톤으로).

상세 보기 (모달 또는 Bottom Sheet):

리스트 클릭 시 아래에서 위로 올라오는 바텀 시트 형태 추천.

[해지하러 가기] 버튼은 시각적으로 매우 명확하고 누르기 쉽게 디자인 (가장 강조되는 메인 액션 버튼 컬러 적용).

📱 2화면: 카테고리별 추천 및 리뷰 (Discover & Reviews)
핵심 목표: 다양한 구독 서비스를 탐색하고, 신뢰도 높은 리뷰를 보고 새로운 구독을 유도하는 것.

상단 카테고리 네비게이션:

좌우 스크롤이 가능한 칩(Chip) 형태의 카테고리 버튼 (전체, OTT, 음악, 가전, 식품 등).

추천 피드/카드:

격자형(Grid) 또는 리스트형 카드.

서비스 로고, 별점(★ 4.8), 한줄 요약 혜택, "첫 달 무료" 등의 프로모션 태그가 강조되어야 함.

리뷰 영역:

사용자들이 직관적으로 볼 수 있는 별점 배치.

장점과 단점이 명확히 구분되어 보이거나, 주요 키워드 태그(#가성비최고, #볼게없음)가 상단에 노출되는 UI.

4. 무드보드 및 레퍼런스 (디자이너 전달용)
디자이너에게 말로 설명하는 것보다 기존 앱을 예시로 드는 것이 가장 확실합니다.

전체적인 지출/대시보드 UI 참고: 토스(Toss) 또는 뱅크샐러드 등의 자산 관리 탭 (불필요한 선을 줄이고 여백과 굵은 폰트로 정보를 전달하는 방식).

리스트 및 해지 UX 참고: '왓섭(Whatsub)' 앱의 구독 리스트 형태 및 해지 알림 화면.

추천/리뷰 탭 참고: '화해(뷰티 리뷰 앱)'의 카테고리 탭 및 유저 리뷰 정렬 방식.
